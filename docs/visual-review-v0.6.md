# 人物・建築の置き換え v0.6

前版の材質調整では参考画像との差が埋まらなかったため、巨人のモデルと街の建物を置き換えた改修です。

- 巨人は Nathan の拡大コピーから Eric の別スキャン・別骨格に変更。顔、体格、襟付き長袖シャツとベストの立体形状が異なります。元の写真テクスチャと法線を使用。
- 主人公は専用のスキニング付きロングジャケットを追加。裾を腰下まで延長し、広がる輪郭、織物UV、折り返した立体襟、ラペル、厚みを作成。革鞄に革のPBR素材、縁、形状の歪みを追加。
- 箱型の家の生成を廃止し、ORCA Bistro 由来の6種の建築モデルに変更。造形された窓枠・軒・装飾・バルコニー・屋根を持つ建物を、運河周辺へ配置。遠景は別LOD。車両・独立した看板・アンテナ等は含めません。
- 建築のUVとPBR素材を維持し、環境光・太陽光を調整。4段のカスケードシャドウで人物から街まで影の描画範囲を拡大。人物資産は従来どおり非公開、CC-BY 4.0 建築は出典と改変内容をクレジット。

30秒の一続きのリプレイ、同じ荷台での上昇と隠密行動を維持しています。

## 検証状況

ローカルのTypeScriptビルド、5件の操作・リプレイ・骨格テストを通過。巨人の分割収録テストは、新しいEricの実骨格で確認しています。本番環境でもモデル変換・ビルド・5件テストが通過。ローカルの0・7.5・25.5・28.5秒と1080p接写を確認し、巨人の顔への衣装材質混入と主人公の肩の隙間を修正済み。Blender 4.0 と 4.3 の書き出し差による半透明設定を検出し、変換時・実行時の両方で不透明材質を明示。本番環境で生成された建築GLBを使うローカル描画でも、面の重なりが解消したことを確認。BC5形式の法線のZ成分も復元し、書き出し済みGLB内の99画像、33法線、33不透明材質を検査して通過。建築変換はBlender 4.3.2に固定。

## 残る差

参考画像と同等という判断には至っていません。光の回り込み、顔の表情・髪、布の動的なしわ、荷台のモデル・テクスチャ、背景との美術的な統一に改善の余地があります。
