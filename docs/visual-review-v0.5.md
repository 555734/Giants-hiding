# 人物改修 v0.5

今回の比較対象は、紺の上着・茶のズボン・革鞄の主人公が木製足場を走り、巨人の作業員と同じ街に存在する想定プレイ画像。

## 実装

- 元のスキャンの骨格と肌のカラー・法線を維持。上着に立体的な裾、ポケット、縫い目とボタンを追加。追加パーツは体に沿わせ、スキャンのUVを参照して素材を合わせた。同じ骨格で変形する。
- 袖の厚みと折り返しを増やし、細分化で輪郭を整えた。肌と布は別材質。
- 元の独立した眼球を抽出し、白目・虹彩・瞳孔と角膜を近似した反射を別材質にした。頭の向きに加えて虹彩の向きを控えめに制御。
- 肌の反射を抑えてスキャンの細部を維持。
- 隠れ姿勢は腰の高さ、前傾、足の前後差、手首の位置を調整。
- 革鞄の肩紐を平たい帯に変更し、靴の現代的な白いラインを材質上で除いた。

## 変わらない条件

30秒・1920×1080・30fps・900フレーム。単一シーン／単一カメラの連続プレイ。物理・リプレイ状態とレンダリングは分離。

## 制約

衣服は既存スキャンを加工した近似であり、専用に作成した衣装スキャンや布シミュレーションではない。肌に真のサブサーフェス散乱はなく、眼球の反射も近似。顔の表情、髪の細かな束、衣装の時代考証、背景の密度には参考画像との差が残る。参考画像の写実性と同等の品質には未到達。

## 検証

モデル変換・TypeScriptビルドと、5件のリプレイ・ポーズ・操作テストを通過。[本番出力 run 27](https://github.com/555734/Giants-hiding/actions/runs/39537125807) は成功。

- 30.000秒、1920×1080、30fps、900フレーム、H.264映像／AAC音声。
- 20区間の間にある19境界について、フレーム番号・時刻・プレイヤー位置・カメラ位置の連続性を検査して通過。
- FFmpegによる全編デコードを通過。取得した公開MP4のffprobeでも仕様を確認。
- エンコード済みMP4から抽出した30画面を目視し、単一シーンの移動・ジャンプ・上昇・しゃがみ・巨人の退避が続くことを確認。これは全フレームの目視検査ではない。
- 終盤は木材の手前を横移動するよう経路を補正。28.5秒と29.9秒の接写でも頭が木材を貫通しないことを確認。
- フォーリー音源のピークは0.439。動画サイズは69,959,585バイト。
